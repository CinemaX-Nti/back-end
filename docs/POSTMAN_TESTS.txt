POSTMAN TESTS INDEX
===================

This file is now split into smaller text files by feature area.

Base URL
http://localhost:5000

General notes
- In this project, routes are mounted directly on `/`, not `/api`.
- Use `Content-Type: application/json` for all POST requests.
- Protected routes need `Authorization: Bearer <TOKEN>`.

Suggested reading / test order
1. `docs/postman-tests/00_overview.txt`
2. `docs/postman-tests/01_users.txt`
3. `docs/postman-tests/02_halls.txt`
4. `docs/postman-tests/03_movies_showtimes_seats.txt`
5. `docs/postman-tests/04_bookings.txt`
6. `docs/postman-tests/05_restaurant.txt`
7. `docs/postman-tests/06_auth_validation.txt`

Useful Postman variables
- baseUrl = http://localhost:5000
- userToken = token from signup/signin
- adminToken = token from admin account
- userId = id from signup response
- confirmationOtp = OTP from email confirmation message
- resetOtp = OTP from password reset email
- deleteProfileOtp = OTP from profile deletion email
- hallId = id from create hall response
- movieId = id from create movie response
- showtimeId = id from create showtime response
- bookingId = id from create booking response

Split files
- `00_overview.txt`: health check and full suggested order
- `01_users.txt`: signup, signin, profile, password, OTP, delete profile, admin users
- `02_halls.txt`: create, list, update, delete halls
- `03_movies_showtimes_seats.txt`: movies, showtimes, seed seats, get seats
- `04_bookings.txt`: create booking, confirm payment, booking expiry, booking race-condition tests
- `05_restaurant.txt`: create and get restaurant menu
- `06_auth_validation.txt`: negative auth / validation scenarios
