USER POSTMAN TESTS
==================

2. Signup
---------
Method: POST
URL: http://localhost:5000/users/signup

Body:
{
  "firstName": "eslam",
  "lastName": "gamal",
  "email": "ahmed@example.com",
  "password": "123456",
  "phoneNumber": "01012345678",
  "dateOfBirth": "2000-05-15"
}

Expected:
- returns `success: true`
- returns `data.user`
- returns `data.requiresEmailConfirmation: true`
- sends a confirmation OTP email

Save:
- user id as `USER_ID`
- confirmation OTP from email inbox as `CONFIRMATION_OTP`


3. Confirm Email

6. Login With Google
--------------------
Method: POST
URL: http://localhost:5000/users/google

Body:
{
  "idToken": "PUT_GOOGLE_ID_TOKEN_HERE"
}

Expected:
- returns `success: true`
- creates a new google user if email does not exist
- returns `data.token`

Required env:
- GOOGLE_CLIENT_ID
- JWT_SECRET


7. Update Password
------------------
Method: PATCH
URL: http://localhost:5000/users/update-password

Headers:
Authorization: Bearer <USER_TOKEN>

Body:
{
  "currentPassword": "123456",
  "newPassword": "12345678"
}

Expected:
- status 200
- returns `success: true`
- `message: "Password updated successfully"`

Notes:
- works only for local accounts
- use the new password in the next signin test


8. Forget Password
------------------
Method: POST
URL: http://localhost:5000/users/forget-password

Body:
{
  "email": "ahmed@example.com"
}

Expected:
- status 200
- returns `success: true`
- returns a generic success message even if the email does not exist
- sends an OTP email if the account is a confirmed local account

Required env:
- EMAIL
- EMAIL_PASSWORD

Save:
- OTP from email inbox as `RESET_OTP`
